# Rencana Konten PrintOS — v1

Dibuat 2026-10-28 · 150 ide · 12 series · 3 project · 24 publikasi · 4 sesi produksi.

Semua ide di bawah ini **bahan mentah**. Tugasmu: tandai yang dipakai, hapus sisanya. 
Tidak ada kewajiban memproduksi 150 ide — pack ini ada supaya kamu tidak pernah kehabisan bahan.

## Cara pakai

1. Di PrintOS: **Backup JSON** dulu (siapa tahu ada data lama).
2. **Import JSON** → pilih `printos-content-pack-v1.json` → periksa ringkasan → terapkan.
3. Import ini **mengosongkan** produk/task/filament/order/finance dan menggantinya dengan rencana konten.
4. Buka Content Studio → filter per series → hapus/arsipkan yang tidak perlu.
5. Untuk 12 ide pertama, pakai **Generate tasks** supaya muncul di Tasks & Schedule.
